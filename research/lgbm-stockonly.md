# lgbm-stockonly — 純個股特徵排序 + 曝險 overlay 分離

**Branch**: `lgbm-stockonly`（parent: `lgbm-rank-v1`）· **日期**: 2026-06-13

## 方法

attempt 3 的模型把 3 個市場狀態特徵混進 X，市場特徵跨過樹分裂閾值時整本書冊大翻轉（單週 11-23 檔），周轉 10-19x/年。本次把「排序」與「曝險」徹底拆開：

- **排序**：`train_lgbm_scores.py --no-market-feats` 重訓，X 只剩 26 個個股橫斷面特徵 → 面板 `lgbm_scores_h21_nomkt`。排序逐日漸變、不再整批翻轉。
- **曝險**：完全交給組合層 overlay — `taiex`（TAIEX≤EMA120 清倉）、新增 **`taiex_half`**（風險關閉降半倉，對沖 2018-19 型 gate 鞭甩、保留 2020/2022 型崩盤保護）、`none`。
- **更寬 band**：band_mult {4,8} × hold_smooth {4,8} × top_n {30,50} × regime {taiex, taiex_half, none}（24 組）。
- **周轉懲罰選參**：train 選擇用 `sharpe − 0.05×ann_turnover`（OOS 仍報原始 Sharpe）；新增通用工具 `scripts/hindsight_best.py`。

## 診斷

1. **鞭甩修復成功**（本次的目的）：周轉 10-19x → **4-8x**，持股紀錄單週最多換 2 檔（前次 11-23 檔）。書冊機制已達工程目標，之後沿用 nomkt 面板做書冊。
2. **但市場特徵的交互 alpha 是真的**：拿掉後天花板在 4/6 段下降（2014-15 跌 0.44、2022-23 跌 0.26）。attempt 3 的鞭甩是「昂貴但有料」——模型在用市場狀態合法地切換書冊風格。下一步要把這份條件 alpha 用便宜的方式接回（曝險層、或雙書冊切換），而非塞回特徵。
3. **taiex_half 是穩健固定選擇**：六段距天花板平均僅 -0.14、從未墊底。把 regime 從格點移除、固定 half，可消掉大半選參錯誤（本次 stage 5 選 none 1.13、half 有 1.68；stage 1 選 none 0.36、half 有 0.97）。
4. **周轉懲罰選參有副作用**：把 stage 1 推向 band 8/sm8（過鈍，0.36），且未能阻止 stage 4/5 選 none。懲罰係數 λ=0.05 偏大、或該懲罰的其實是 regime 翻轉而非總周轉。
5. **弱段 alpha 瓶頸實錘**：2014-15 / 2018-19 天花板只剩 0.99 / 1.09 — 純價量、純個股特徵在這些年代就是只有這麼多魚。required: 新資料（2018 後基本面/籌碼拼接、月營收）或多 horizon。

差距：0/6 達標；最佳 stage 2 的 1.71 距 2 還差 0.29；天花板 >2 只有 2/6 段（2.24 / 2.11）。即使選參完美也只能 2/6 — alpha 量不足是主瓶頸，書冊機制已不是。

3. **固定 regime=taiex_half**（移出格點）+ 把周轉懲罰改成 regime 翻轉懲罰或調小 λ。
4. 條件 alpha 的便宜回收：用市場狀態做「防守書/進攻書」二選一（兩本都來自 nomkt 排序的不同 top_n/風格切片），切換成本遠低於整本重排。
